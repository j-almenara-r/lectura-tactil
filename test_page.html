🎯 Section 1: Welcome

This is a test page for the Snap Scroll extension with Reading Mode (F9) support. Try scrolling or using keyboard shortcuts to navigate between discrete pages.

Instructions:
1. Install the Lectura Táctil extension
2. Press F9 to toggle reading mode
3. Or enable it from the popup
4. Scroll or use keyboard shortcuts

📱 Section 2: Reading Mode

The reading mode feature creates discrete page-like sections with snap scroll. Press F9 to toggle, just like Microsoft Edge's reading mode!

⌨️ Section 3: Keyboard Navigation

Use F9 to toggle reading mode. Then use Space or Page Down to go to the next page, and Page Up to go to the previous page!

🌐 Section 4: Discrete Pages

This extension works on any webpage with discrete page-like sections. The algorithm automatically detects content and creates clear page boundaries for a book-like reading experience.

✅ Section 5: Conclusion

Enjoy a better reading experience with discrete pages! Toggle reading mode with F9 or use the extension popup anytime.
