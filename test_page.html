🎯 Section 1: Welcome

This is a test page for the Snap Scroll extension. Try scrolling or using the Space/PageDown keys to navigate between sections.

Instructions:
1. Install the Snap Scroll extension
2. Enable it from the popup
3. Scroll or use keyboard shortcuts

📱 Section 2: Features

The snap scroll feature automatically aligns content sections as you scroll, making it easier to focus on one section at a time.

⌨️ Section 3: Keyboard Navigation

Use Space or PageDown to go to the next section, and PageUp to go to the previous section. It's that simple!

🌐 Section 4: Universal

This extension works on any webpage. The algorithm automatically detects content sections and applies snap points.

✅ Section 5: Conclusion

Enjoy a better reading experience with Snap Scroll! Toggle it on or off anytime from the extension popup.
